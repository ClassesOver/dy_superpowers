# 架构场景

- 无 `trace_id` 的 MCP 调用应被拒绝或标为无关联调用。
- 运行追踪中的令牌、密码、密钥和人力资源/生产业务载荷必须脱敏或省略。
- 缺少目标、读写属性或验证方法的计划不能通过校验。
- 当前工作区记忆路径只能落在工作区 `.dy_superpowers/` 下。
- 没有结束事件的 trace 必须保持中断/未知，不能显示为成功。
- 畸形 JSON 应返回解析错误，MCP 进程继续处理后续请求。
- 工具调用成功或失败都应产生结束事件；业务事件不能伪造工具生命周期事件。
- trace 应保留巡检技能、检查顺序、调研点、结果和证据引用等无敏感内容的关联字段。
- 计划校验通过不能被当作执行授权。
- 记忆只允许读写当前工作区白名单 Markdown 文件，写入须经用户明确确认。
