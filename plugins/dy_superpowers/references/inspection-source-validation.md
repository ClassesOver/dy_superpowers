# 来源驱动巡检

调研 guide 仅用于问答调研，不作为巡检标准或程序化解析输入；巡检通过 dy_inspection_prepare 读取最新发布模板目录、确认答案及绑定附件要求。

两模块当前模板的问题集为权威，分母按实际模板计算，指引仅业务投影。聊天和答卷共用版本化QA，旧答案不迁移。dy_research_answers_import仅解析候选不写记忆，已有完整性沿用、新项false，明确确认才提升。dy_research_answers_save在业务确认和保存授权后按问题revision整批校验、整项替换，其他问题保留，回读answer_version与同步答卷path；下载export另生成登记副本，不改不可变版本原件。

只引用当前scope同question_id的确认答案和绑定附件hash，附件全部已确认要求逐项覆盖。模板、答案版本或摘要变化须重新确认和prepare。原材料明细按引用回查，不声称全部记忆。配置观察不是业务批准或验收。

Odoo证据需本workspace成功读取事件和同span成功tool.end，匹配basis及question_id/answer_revision。文档需真实文件摘要，人工需可追踪签认材料。伪造reference、跨范围/模块/环境、漏题、漏附件要求均拒绝。未验证题保留待确认/未检查，报告覆盖当前模板全部问题并说明自由文本语义理解边界。
