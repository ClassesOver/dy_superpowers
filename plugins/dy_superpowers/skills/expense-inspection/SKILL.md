# 费用模块巡检

读取当前业务范围的最新确认答卷及附件，利用现有知识检索和 Odoo 只读工具，核对当前系统是否满足答卷要求。按[巡检通用流程](../../references/inspection-workflow.md)执行，本文件只列费用领域差异。

当前费用模板提供问题范围，同范围最新确认答案和绑定附件定义业务要求。模块标识expense，完整覆盖当前模板的全部question_id，分母取自prepare返回的expected_checks，原分组和编号用于展示，内部唯一question_id不改造或补号。

## 领域重点

技术配方见[费用源码与查询](references/source-queries.md)。重点核对：单据类型与编号的公司范围、费用政策头与明细的业务日期边界、城市淡旺季、单据权限的部门、员工及提交/查询范围、预算控制与专项经费规则、费用制证规则、费用期间状态与总账期间的区别；如本期交付 OCR 席别识别，另核对席别映射的唯一命中。
