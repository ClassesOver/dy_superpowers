# 通用配置

## 输入与边界

输入：需求、项目/环境 URL、数据库、Odoo 主版本及模块版本、公司/院区、配置范围、业务生效日期、执行账号和验收标准。缺失项先只读核对，不从样例猜值。输出：依赖分析、精确变更预览、MCP 执行结果、数据回读与浏览器验收分别判定的中文报告。

只使用 `dy_knowledge_*` 定位知识、`dy_odoo_*` 核对和修改账套。Knowledge 不执行配置、不授予写入权限。不得通过脚本、浏览器、直连 RPC、SQL 或数据库旁路执行 Odoo 读写；Playwright 仅用于同记录的界面验收。工具不存在、写入未启用或白名单不支持时暂停相关项，不改用旁路。

## 检索与分析

1. 用业务词、模块名或模型名作为 `query` 调用 `dy_knowledge_search`，默认按字面文本搜索 Zoekt 源码及业务摘要；必要时用 `module`、`knowledge_type=source/summary` 和 `limit` 缩小返回范围。不使用 `model` 或字段/约束等语义过滤。命中后按带索引版本的 `reference` 调用 `dy_knowledge_read`，按 `next_offset` 续读至 `complete=true`，而非每轮扫描仓库；引用失效时重新搜索。
2. 从业务词逐步定位模块 → 模型 → 字段/方法 → 相关约束、计算、关联、菜单和权限代码。模块声明依赖、继承与字段关联属于源码事实；业务解释、推断和建议操作顺序另列，不把调用关系或 manifest 依赖直接转成配置顺序。
3. 用 `dy_odoo_module_info`、`dy_odoo_model_fields`、`dy_odoo_record_search/read` 核对当前环境的安装版本、字段、原生权限及已有记录。模块和记录满页须继续分页，避免将未读取判成不存在。
4. 列出可复用记录的真实 ID、公司/日期适用范围，缺失前置项、候选冲突、证据缺口及建议顺序。依赖由模型结合规则、相关代码和当前账套事实判断，不套用固定领域顺序。只暂停受阻项，独立且已授权项可以继续。

没有结果、代码读取不完整、覆盖状态为部分、来源版本不匹配时，明确哪些判断缺少依据；不据此生成确定结论。OdooForge 仅用于开发期参考实现迁移，不作为外部依赖或运行时知识来源。源码模块版本一致也不能证明部署代码完全相同。

费用场景按需读取[费用定位](references/expense.md)；总账场景读取[总账定位](references/general-ledger.md)。这两份参考不是预置依赖答案。

## 确认与执行

展示本批环境、数据库、公司、创建/更新操作、模型、已有记录 ID、逐字段旧值/新值、关联 ID、影响范围、潜在副作用、恢复方案及待验收项，再请求用户明确确认。知识引用和项目记忆不构成确认。确认只覆盖展示的精确变更；范围、字段、环境或顺序发生实质变化须重新确认。

读取 MCP 工具 schema 和[写入合同](../../docs/odoo-config-engine.md)，按工具公开预览/摘要契约取得确认摘要，不伪造确认令牌。服务端写入默认关闭；须由环境管理员显式开启，技能本身不修改启用开关。

确认后逐步调用 `dy_odoo_record_create/update`，使用真实返回 ID 连接后续配置。复用已存在且适用的记录，不盲目新建；同名但跨公司、候选不唯一、关联不明确均暂停。更新需携带旧值/并发前提和幂等键。不得猜 ID 或把业务交易、审批、过账、模块安装纳入配置写入。

超时、连接中断或结果 `unknown`：保留原幂等键，先用 MCP 按确认的唯一键、公司和目标字段查明实际结果；不换键重试，不重新发起同一写入。结果未唯一确认前暂停其后续关联操作。回读不符时记录差异，暂停依赖项，不自动回滚或覆盖；修复另行预览确认。

## 双重验收与记忆

每条配置使用[统一回读模板](references/acceptance.md)。MCP 自动回读之后，仍检查目标公司、全部预期字段、关联 ID 和实际业务适用范围；Knowledge 引用只解释规则，不代替实时证据。

浏览器使用 Playwright，在相同受信环境、数据库、公司上下文打开真实返回 ID 对应表单；核对记录身份、可见字段及关联显示，截图并记录页面、时间、公司和记录 ID。不得通过浏览器修改配置，不导出登录态、密码或令牌；截图与报告保存到当前工作区 `.dy_superpowers/configuration/`，不写入插件。

数据回读通过与浏览器验收通过分别记录。只有两者均通过，本批才可标记“配置验收完成”。浏览器不可用、403、公司不一致、截图不能证明目标记录或验收未执行时，明确“数据已验证，浏览器待验收”，不降低批次标准、不伪造截图；已授权且不依赖界面结论的步骤可以继续。

配置操作的幂等状态由 MCP 保存，不等于项目调研结论。新增项目事实/记忆正文须展示并经用户确认，通过现有记忆工具写入当前工作区；不把源码索引、来源审计或线上返回行批量写入业务记忆。
