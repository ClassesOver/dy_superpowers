# Odoo 配置引擎边界

首期兼容目标为 Odoo 12。当前运行时已提供受限的 Odoo XML-RPC 只读连接器；不执行远程写入、SQL 或模块安装。

添加连接器前，记录目标的准确 Odoo 修订版本、社区版/企业版类型、已安装模块、自定义附加模块（addon）、数据库、部署形态、开放的远程过程调用（RPC）/应用程序接口（API）和服务身份。不得根据其他 Odoo 主版本推断兼容性。

当前适配器提供 `search_read`、指定 ID 读取、`fields_get`、已安装模块列表及模块信息读取。连接参数来自 `ODOO_URL`、`ODOO_DB`、`ODOO_USERNAME`、`ODOO_PASSWORD` 环境变量，不设置凭据默认值。通用搜索限制模型名格式、结果条数和只读方法；记录读取最多 100 条；已安装模块列表每页最多 100 条，需用 offset 翻页取全量；连接和 Odoo Fault 对外返回脱敏错误。调用者仍须按目标公司、业务和期间选择最小必要 domain 与字段，并验证服务账号的公司访问范围；只读不等同于数据最小化，也不能替代 Odoo 侧权限配置。

后续若增加写操作，必须声明目标、读写模式、风险、所需权限、幂等性、前置条件、审批要求、失败语义、恢复路径和操作后验证。直接 SQL 写入和代码生成不在当前范围。当前能力不支持的需求转为外部开发或人工工作项。
