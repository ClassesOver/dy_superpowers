# 来源适配器契约

每个适配器声明来源类型、负责事实类别的权威性、读写模式、目标标识、凭据来源、刷新方式和支持字段。结果携带来源引用、读取时间、版本标识以及新鲜度和可用状态。

首批运行时适配器包含 Odoo 12 JSON-RPC 只读适配器（`/jsonrpc` 端点，仅用标准库，XML-RPC 已弃用）。它支持受限的 `search_read`、指定记录读取、字段元数据读取和模块状态读取，连接参数从 `ODOO_URL`、`ODOO_DB`、`ODOO_USERNAME`、`ODOO_PASSWORD` 环境变量读取，请求超时由 `DY_ODOO_TIMEOUT` 控制（默认 15 秒），默认最多返回 100 条记录。客户端只允许 `search_read` 和 `fields_get` 两个只读方法，远端错误正文不会透传。不可用的来源应作为覆盖缺口明确报告；不得用记忆填补当前事实。任意方法调用、写入、SQL 和模块管理不在适配器范围内。
