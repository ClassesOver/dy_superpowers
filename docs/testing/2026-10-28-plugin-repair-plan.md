## 已观察的失败基线

- 新增闭环测试初次 6 failed：填写模板无候选、正文待确认未计数、未知完整性被计完成、未授权读取清单、同步失败被当成功返回。
- 新增分页测试初次失败：超过 100 条记录直接报错。
- 多表测试初次失败：第二张独立结果表被忽略。
- 原生安装启动测试：原 `${PLUGIN_ROOT}` 参数未展开；只有市场安装成功不能证明 MCP 可启动。
- Skill 行为基线见同目录真实双场景与详细日志报告；本轮不得用字符串断言代替真实行为验证。

## 环境前提

- 系统 python3 没有 pytest；使用插件现有锁定虚拟环境。
- 安装测试写 uv 缓存、启动本地协议服务需提权；沙箱阻止缓存写入/本地 socket 不算产品通过。
- 新入口须在启动 Codex 前设置 `DY_WORKSPACE_ROOT`，不猜测业务目录、不把插件目录作为业务记忆。
